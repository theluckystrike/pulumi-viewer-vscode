# Changelog

## 0.1.0

- First release: `Pulumi.yaml`, `Pulumi.yml`, `Pulumi.*.yaml` and `Pulumi.*.yml` in a read-only offline viewer, parsed locally with plain JavaScript and zero Pulumi CLI, shell or cloud calls.
- Project, runtime and backend metadata viewer, stack config key/value table with encrypted `secure:` values flagged and masked, and static security findings (plaintext secrets, missing `secretsprovider`, hardcoded AWS/GCP/Azure tokens, unpinned runtime or plugin versions).
- Zovo Pro tools with 1 free try each: Markdown stack secret-hygiene and config audit, two-stack Markdown diff (dev vs prod), and Markdown/CSV redacted stack configuration inventory export. Get Zovo Pro first shows what Pro includes and the tries left, in an editor tab.
